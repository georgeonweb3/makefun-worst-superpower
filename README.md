One line inventing the most useless superpower imaginable: a power so pointless that naming it is the whole joke. Judged head to head in pairs on how genuinely useless the power is, how funny it is to picture in use, how unexpected it is, and how tight and specific the wording is. Free to enter.

The entry (140 characters):

> I can make any dog respect me instantly, for exactly two seconds, once a week, so the park poodle has seen me obeyed seven times since 2019.

Dog respect — but only two seconds of it, once a week — so the sum total of a lifetime of heroics is a park poodle who has watched it happen seven times since 2019. Three beats (power / two-second limit / the poodle's count), ending on a number-and-time punch.

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (UTF-8, 1–140 characters, no trailing newline). Override the output path with `ENTRY_OUTPUT` if the harness needs a different location:

```sh
ENTRY_OUTPUT=/tmp/entry.txt python3 main.py
```
